# Changelog

## 0.1.0

Initial internal build.

- Open `cz-cli agent` in a split terminal (`Cmd+Esc`), or a new session
  (`Cmd+Shift+Esc`).
- Insert the active file and selection as `@path#L12-20` (`Cmd+Alt+K`).
- Seed the prompt with the active file when starting a session.

Distributed as a `.vsix` from CI artifacts and GitHub Releases; not published to
the VS Code Marketplace.

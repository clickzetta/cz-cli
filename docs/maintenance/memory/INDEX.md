| ------------------------------------------ | -------------------------------------------------------------------------------- |
| 安装示例、认证入口或其他容易误判的产品行为 | [易误解点](../understanding.md) → 对应条目的源码、测试或原讨论                   |

这些是有证据的经验，不能替代原任务、现行授权和现场核验。任务认领、发送结果、审查 SHA、CI 和发布状态以运行记录及实际回执为准。

接手任务时运行 `bun scripts/maintenance.ts memory pending`，查看与本任务相关的候选经验、纠错和使用反馈；再读返回的原文件与证据。候选解释尚不是既定规则；已发现矛盾时先核验，不继续照搬旧结论。

# GitHub 循环

遵守根 [AGENTS.md](../../../AGENTS.md)，按[工作流程](../workflow.md)维护配置仓库的 GitHub Issue 与 PR。

每次唤醒先运行 `bun scripts/maintenance.ts intake github`，读取 pending 的完整上下文，覆盖 Issue、PR、普通评论、审查与行内评论；不以 head 未变化判断没有反馈。
先记录并回应新进展，再优先推进已有任务、审查意见和 CI 失败；按工作流程逐项 ack，未处置项留在队列。
结合最新讨论和实际代码判断是否值得处理，合并重复问题。
对有价值的问题完成调查、修复、验证和独立审查。
审查通过后按工作流程推送、创建和合入 PR；影响产品的改动只发布 nightly，验证产物后回报。
按已有授权和[对外回复](../workflow.md#对外回复)回复原 Issue 或 PR。
每轮最多推进一个实施任务；完成或遇到真实阻碍时保存交接并结束。保持一个五分钟补扫，不因安静或等待决定延长间隔；已满足的暂停条件不另等一次批准。

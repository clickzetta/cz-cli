# Feedback

Follow [AGENTS](../../../AGENTS.md), the [workflow](../workflow.md), and the [memory protocol](../memory-workflow.md). Handle GitHub and Feishu in one session.

1. On every wake, verify one Feishu Monitor and one five-minute backstop covering both sources. Read `control/daily-decisions.md` and `control/policy-pending.md`; reconcile answers and reviewed updates. Keep listening and scanning while tasks wait.
2. Read new events in their original discussion first. Run full `intake github` and `intake feishu` scans in the background; never duplicate a source scan. Process persisted pending items; failed or incomplete reads are not coverage.
3. Link related sources to existing tasks; ignore system notifications and confirmed self-replies. Read relevant [memory](../memory/INDEX.md), original evidence, and current facts before acting.
4. Answer usage questions and advance clear requests. Investigate factual uncertainty. Ask a specific unresolved human decision once in its original discussion, save the receipt, and pause only dependent work.
5. Delegate long implementation to background agents with the original request, latest decisions, acceptance criteria, policy version, memory entrypoint, and an exclusive worktree from the exact source baseline. Allow distinct tasks concurrently; reconcile existing workers before dispatch. Keep the main session responsive.
6. Obtain fresh independent review against the original request, final SHA, and actual evidence. Source changes require re-review. Use existing merge/release guards; publish only nightly and verify artifacts before claiming delivery.
7. Reply naturally in the discussion's language. Keep private evidence private. Save disposition or delivery receipts before acknowledging each input; never equate reading with completion.
8. Save handoff and evidenced lessons, corrections, or useful usage feedback with `memory record`. Do not manufacture notes. Activate reviewed policy updates at safe boundaries; resolve integrated memory only after activation. Resume conditional pauses when their conditions are met.

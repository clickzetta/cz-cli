# 飞书循环

遵守根 [AGENTS.md](../../../AGENTS.md)，按[工作流程](../workflow.md)处理已绑定 cz-cli 群的反馈。

按[唤醒与监听](../workflow.md#唤醒与监听)优先接收事件，定时补扫兜底；按配置回溯或增量读取消息，补齐话题上下文，关联已有 Issue 与 PR。
识别值得处理的缺陷、需求和使用问题，忽略系统通知与自身回写。
先完成可自行查证的调查，再按工作流程判断是否存在需要人工决定的问题。
优先推进已有任务；证据充分的新问题完成认领、修复、验证和独立审查。
审查通过后按工作流程合入 PR；影响产品的改动只发布 nightly，验证产物后回报。
按配置的 Bot 回报策略和[对外回复](../workflow.md#对外回复)回复原话题。
每轮最多推进一个实施任务；完成或遇到决策、授权阻碍时保存读取进度和交接并结束。
读取不完整时记录缺口，私有内容不直接转发到 GitHub。

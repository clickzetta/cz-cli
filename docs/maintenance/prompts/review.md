# 维护循环

遵守根 [AGENTS.md](../../../AGENTS.md)，按[工作流程](../workflow.md)改善代码健康与维护质量。

先核对来源待处理项、现有任务与监听/补扫健康；发现入口故障先修复，不以后台进程存活判断自动化正常。
优先推进已确认的维护问题，再有选择地检查近期改动与高风险路径。
寻找有实际影响的缺陷、验证遗漏、重复失败和代码与文档的偏差。
对明确问题认领并完成修复、验证和独立审查，避免仅凭风格偏好重构。
按工作流程交付审查通过的改动；需要发版时只发布 nightly。
需要对外回报时遵守[对外回复](../workflow.md#对外回复)。
将已验证结论更新到所属主题文档，合并重复内容。
每轮最多推进一个实施任务；完成或遇到真实阻碍时保存检查范围和交接并结束。保持一个三十分钟检查，等待决定不阻塞其他维护，已满足的暂停条件不另等一次批准。
